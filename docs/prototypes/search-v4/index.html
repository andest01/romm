v4 is the v3 header with every dropped feature that could be drawn put back (table above). Try it: type "astral" (relevance order appears), open Sort, group A to Z, tick a checkbox then shift-click another, press Ctrl/Cmd+A, Esc, or / ; open a ⋯ menu; Manage collections; flip "Group versions". Illustrative, made-up data (about 600 roms). The 25% sidebar is today's FilterDrawer, docked instead of hidden behind a button, with the same sections, labels, controls and behavior: 11 tri-state properties, the platform multi-select, 13 searchable multi-selects each with its any/all/none logic, the game-length range, active-count tag, Save as smart collection and Reset. Every control filters the results live. Icons are letter badges here; the real component uses its mdi icons.
