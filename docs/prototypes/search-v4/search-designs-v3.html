v3: one compact header band (search, + Add a filter, Advanced mode, view toggle) with simple summary pills below it; Advanced mode swings out the full filter panel, and pills and panel share one state. Illustrative, made-up data (about 600 roms). Every control filters the results live. Icons are letter badges here; the real component uses its mdi icons.
